# Joga Books 📚

**Tu libro de no ficcion, en horas. No en anos.**

PWA que genera libros completos de no ficcion con IA.
Elige tu nicho, la IA crea el outline y escribe cada capitulo.
El humanizador convierte el texto en tu voz.

---

## Que hace

- Genera 5 opciones de titulo para tu nicho
- Crea outline completo de 12 capitulos
- Escribe cada capitulo (900-1200 palabras)
- Humanizador con 3 tonos: Profesional, Conversacional, Motivacional
- Guarda multiples libros en tu dispositivo
- Funciona offline (PWA)
- Bilingue ES / EN

## Stack

HTML + CSS + JS puro · GitHub Pages · Cloudflare Worker · Claude API
